# Contributing

When opening an issue or proposing an API example, include enough detail for someone else to reproduce the problem:

- Minecraft and NeoForge versions.
- The exact Gradle command used.
- The first relevant error and surrounding stack trace.
- Steps to reproduce the issue.
- Whether `spotlessApply` was run before the build.

For documentation examples, keep code aligned with the actual source signatures and say when a snippet is only a skeleton. Add-on-specific assets should use the add-on's own namespace.

This project is based on the existing [IC2R port](https://github.com/neo-industrial-mc/IC2R). Please preserve relevant attribution and licensing notices when redistributing derived code or assets.
